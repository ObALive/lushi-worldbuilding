# 源灵学苑

[在 My Project 中编辑](https://chatgpt.com/space/page_80566257b7f8819188ad01ac20948938)

**概述**：源灵学苑是由"源灵生命"（公司）为唯一股东设立的私立小学、中学、大学园区，广泛收纳 [罗瓦伊](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E7%BD%97%E7%93%A6%E4%BC%8A.md) 各地的弃儿孤儿，表面为公益学区，实际是源灵公司以生物实验为目的运作的"国中之国"式封闭园区。

## 基本信息

| 项目 | 内容 |
|---|---|
| 性质 | 私立学校＋公司体系 |
| 上级 | 源灵生命 |
| 下属/分支 | 小学、中学（含初高中）、大学；竞赛班/尖子班/特殊能力班等学部细分（见"学制与学部"） |
| 所在地 | [罗瓦伊](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E7%BD%97%E7%93%A6%E4%BC%8A.md)内某教育立法落后、无话语权的小国（国名未具名） |

## 宗旨与运作

- 对外口径（公益）：以源灵生命为唯一股东建立的私立小学，中学，大学都设立在源灵学苑当中；广泛收纳来自罗瓦伊各地的弃儿孤儿，在提供生活保障的同时提供教育，很大程度上缓解了罗瓦伊的弃儿问题，但是从另一个方面也增加了罗瓦伊儿童的被遗弃率。
学苑所在国的教育立法不健全，公司在当地设立了相对封闭的管理体系。

- 实际目的：生物实验。低下的教育水平其实是愚民政策的变种；每年接种三四次疫苗，基本每次都是一次生物实验；源灵暗中扩大地区性季节性流感影响以推动接种，在进行生物实验的同时也在学苑周边地区捞上一笔疫苗订购钱；一人一卡一ID的管理制度，没有卡则事事难行，甚至厕所也需要刷卡进入，便于长周期跟踪实验。
园区形成“国中之国”式社会，居民基本由招入的孤儿组成，管理层由源灵公司的职员组成，拥有独立的法律、税收和管理体系。

## 学制与学部

- 对于全体学生，学校提供最低限度的宿舍与饮食保障，且不同学部有不同的基础奖学金。

- 中学学部为初中到高中共用一套学部体系（合称中学）——魏淳（高二）中学部三年与高中部三年均在同一学部就读。

- 体制：孤儿院保障至小学毕业止 → 之后要么肄业打工、要么边打工边读中学；中学教育长达十年；学苑商铺与基础设施雇员基本是招入的孤儿；结业者保底可读源灵设立的学校；少数天赋者入"尖子班"，真正通过考试出国融入正常社会。

- 小学：灌输"人命有别"的阶级思想，以选拔"听话"苗子；刻意选服从长辈而非能力拔群者当班干部；对能力卓越者做分离式培养入学科/体育竞赛班艺术竞赛无独立班、支持很少；竞赛班即学生口中的"爽班"。

- 初中：按成绩分层设班，另有瞄准国际竞赛的班级，以小学竞赛班为主；特殊能力者入特殊能力班，内部再分层且分层标准不公开，高层班课程表与其他班错开、无共同课间。

- 高中：一校扮演职校/普校/一流校三种职能；分为文部、理部、"技能精英"培养部；各部内按成绩严格分班；竞赛班取消，特殊能力学部保留，按能力作用分十余个班，为分班最混乱的学部。

## 生活

- 源灵学苑的每一个人都有自己独一份的过往

- 很少有人调侃出身，再出生在怎样的贵族，也改变不了他们是被遗弃的孩子的事实

- 大部分学生选择留苑一辈子

- 因想拿文凭而来读书的父母健在的人反而被讥讽。

## 历史

1898 年的[源灵学院变故](../05-%E5%8E%86%E5%8F%B2%E4%BA%8B%E4%BB%B6/%E6%BA%90%E7%81%B5%E5%AD%A6%E9%99%A2%E5%8F%98%E6%95%85.md)中，大量学生及滞留在源灵的人员初次进入社会。
