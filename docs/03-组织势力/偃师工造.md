# 偃师工造

[在 My Project 中编辑](https://chatgpt.com/space/page_7f8755c2077481918ad5a6e230eac64d)

**概述**：偃师工造是一家军工公司，以"全仿真人脑"思维系统闻名，提出并量产"HAIA 协议机"（人类—人工智能连携协议，音译"海鸦"），将作战操作交由人工智能、战略目标交由人类。其产品向国家军队、跨国企业与雇佣兵团体等所有有实力采购的组织开放。

## 基本信息

| 项目 | 内容 |
|---|---|
| 性质 | 军工企业（AI/人形武器研发与销售） |
| 下属/分支 | HAIA 协议机产品线、HAIA 协议军架构（概念） |
| 关键成员 | 总工程师（代号"偃师"） |

## 宗旨与运作

- 产品哲学："错误与抽象本身就是人脑功能不可分割的部分"（偃师之语，记录003）；坚持"人脑各功能缺一不可"，以全仿真人脑系统区别于其他军工公司"依赖大规模训练集的浅层模拟"。

- 销售政策：HAIA 协议机开放给"所有有实力采购的组织——无论是国家军队、跨国企业还是雇佣兵团体"。

- 影响：该协议改变了“人员/装备”的军制界定，下一阶段战争是“军制竞赛”而非单纯的军备竞赛。

## 组织结构

公司的总工程师以“偃师”为代号。

- 概念性单位"HAIA 协议军"：一名人类指挥员 + 一名协议机战术中枢 + 若干协议机分控的无人化装备与战斗单元。

## 技术与产品

### HAIA 协议（人类—人工智能连携协议，“海鸦”）

- 定义："作战装备的驾驶、瞄准与操纵等技术性操作由人工智能完成，而战略与目标则由人类下达"。

- 三层架构：

  - 战略层（人类优先）：人类给出方针与目标。

  - 战术层（AI 优先）：协议机瞬时接管战术细节，以人类无法企及的速度与精度操控装备。

  - 紧急层（协商/冲突）：命令与伦理或生存逻辑矛盾时，协议机进行独立判断；人类可用强制覆盖指令，但"可能导致机体稳定性下降或人格系统受损"。

- 协议机特性：改造型"不仅具备独立人格与情感思维，还能在极端条件下独立判断目标的合理性——有时甚至会在道德难题或绝境中拒绝执行命令"；此特性"常令军官们愤慨，却也在多次实战中挽救了整个作战群"。

### HAIA 协议机（人形机）

- 平时以人形在兵营活动，"生活方式与普通士兵无异"；战斗时进入专用接口舱，神经网络与重型作战机体或载具群相连，动念即可操控整套装备。

- 权限：通常机体权限掌握在协议机手中；人类驾驶员要取得直接指挥权，须"通过唯一密钥以及其他认证方式获得授权许可"。

- 交流界面：偃师工造曾坚持在驾驶员舱设置全息投影增强交流，军官强烈反对，妥协为"投影只在非战斗状态下启用"。

- 协议机模糊了人员（能判断协作、受军法军饷管理）与装备（可被部署调用、会拒绝命令）的界限，引发军制与管理困境。

## 与其他势力的关系

- **军方客户**：采购订单方（见记录003）；对协议机"拒绝命令"多有抱怨。

- **[盖维小队](%E7%9B%96%E7%BB%B4%E5%B0%8F%E9%98%9F.md)**：由偃师工造制造并直属公司，外界尚无确凿证据知晓该小队的所属。

- **独立团体**：独立性较高的团体和个人常租借装备与协议机组建自己的 HAIA 小队，执行原本由雇佣兵集团执行的任务。
