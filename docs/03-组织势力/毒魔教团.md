# 毒魔教团

[在 My Project 中编辑](https://chatgpt.com/space/page_982296806ee8819181b25b1b078e8a1b)

毒魔教团是崇奉[梅蒂欣](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E6%A2%85%E8%92%82%E6%AC%A3.md)的宗教组织，拥有世代传承的祭司容器制度，并以地下势力的形式在[柏格宁](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E6%9F%8F%E6%A0%BC%E5%AE%81.md)等地活动。教团掌握强大的资本与武装力量，能够向政府施压，推动管制药物合法化，并将影响扩展到周边国家。

## 宗旨与运作

教团以药物使用者群体作为重要的社会基础，通过药物经营扩大影响并组织外围人手。教内信仰强调在幻觉与兴奋中同梅蒂欣通联，将改变意识的体验赋予宗教意义。教团强制要求成员服用药物，并借助药物依赖强化服从；极少数上层组织者享有豁免。

教团将祭司容器的身体视为梅蒂欣的所有物。[以西结](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E4%BB%A5%E8%A5%BF%E7%BB%93.md)在二十一岁前接受修行，被送往其他城市，以教团给定的身份独立生活并谋求生计。

## 柏格宁活动

教团在柏格宁兜售管制药物，以倾销方式争夺市场及药物使用者群体中的话语权。较低的售价压缩了利润空间，受其影响的人群首先具有可驱使的外围人员价值，同时也是药物顾客。

当地分支以弱化大众对管制药物的警惕、扩大社会接受度为主要目标，试图使药物使用融入日常生活，形成围绕成瘾体验的文化。战后补偿不足、生活长期困顿的灾民是其重要接触群体，生活中的痛苦与缺乏慰藉为药物传播提供了条件。

基层传教者大多真诚地相信自己在带来慰藉和救赎，其中许多人本身就是受难者与药物使用者。他们通过自身经历理解教内信仰，并将药物带来的体验赋予同梅蒂欣通联的意义。

为避开[世界警署](%E4%B8%96%E7%95%8C%E8%AD%A6%E7%BD%B2.md)，当地分支采用游击式活动，向接触对象传递集会消息，在指定时间与地点开展小型宗教集会。地方负责人带领核心成员在废城区的废弃建筑中落脚居住。

本地黑道原本偶尔经营毒品生意，教团进入后占据明显优势，引起了当地势力的不满。地方黑道更看重手中规模更大的码头经济利益，因而暂时容忍教团在药物市场上的扩张。

教团在当地维持隐秘活动，通过线人观察具有潜力的人选。对于以“报童”之名活动的[观](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E8%A7%82.md)，其判断建立在她表现出的实力与失忆状况上。线人经过几日观察确认她确实失忆，教团便希望利用这一认识空白拉拢她，并灌输有利于“毒”的观念。

废弃商场冲突后，秦若孚已经接触教团人员与活动，又以行动表现出敌意。她的实力和所掌握的信息共同构成隐患，教团将其列为清除目标，同时继续维护当地活动的隐秘性。

## 组织结构

- **以西结（世代代号）**：教内"始终有一个叫做以西结的角色"，青年男性亚人种（鸽子×山羊混种），21 岁前蒙面；21 岁后成为梅蒂欣附身降临的容器，并主持教内一切重大祭司活动，21 岁前此任务由教内主祭承担；"每一代以西结都会在 28 岁死去，新一代的'以西结'会同时诞生"。

- **童子**：21 岁前蒙面的以西结有两名引路童子，在以西结 21 岁接任祭司的成人礼上被杀作仪式用；童子被熏哑喉咙、不能言语。

- 教内另有主祭一职与“教内规训”体系。
