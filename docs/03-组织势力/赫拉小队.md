# 赫拉小队

[在 My Project 中编辑](https://chatgpt.com/space/page_413ed7e5e4c08191a28e36c692cc4f04)

**概述**：赫拉小队即**行脚商小队**，是一支由来自不同地区的人组成的同行小队，职业见[行脚商](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E8%A1%8C%E8%84%9A%E5%95%86.md)。队长为仪。观（秦若孚）先在柏格宁独自发展，与主角随本队从城外入城后二人才相遇；“秦若孚”一名即队长所起；相遇后她入队，并与小队一同租住[柏格宁房东](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E6%9F%8F%E6%A0%BC%E5%AE%81%E6%88%BF%E4%B8%9C.md)的别墅。

## 宗旨与运作

- 队伍性质：行脚商这类职业“同行之间的默契比实力更加重要”，因此这支成员来自不同地区的小队“可堪罕见”——“光听名字大致就能看出这是一支由来自不同地区的人组成的小队”。

- 入队教学：从一开始，赫拉小队就一直向秦若孚"科普"一些她所不知道的知识；她学得很快，"也在逐渐的靠着这些知识去熟悉这个法术，神明，科技共存的社会是如何运作的"。

- **秦若孚的隐忧**：表面上看，对小队众人来说这一切都像“多了一个聊天的伙伴”一样轻松；但随着秦若孚学到的东西越多，她越“捉摸不透这样一支小队为什么有兴趣将自己吸纳其中”。

## 组织结构

小队由来自不同地区的人组成，已知成员为队长仪、邘陇、潘、狄俄斯，另有一名成员未具名；秦若孚于柏格宁相遇后入队。

### 队长：仪

- 没有将真名告诉别人，始终自称为"仪"。

- 秦若孚眼中的印象：沉稳——适时地沉默，适时的出声，适时的微笑，像是每时每刻都在执行能够达成他的目的的最优解；秦若孚进而猜度他在自己人面前非常好相处、而在路人、他人或敌人面前"又是一种完全不一样的形象"。

- 备注：为秦若孚命名。

### 潘

- 单名一个"潘"字。

- 在小队里举止最随意、最快与秦若孚熟络的人。

- 不论在什么季节都穿着无袖的衣服，"据他所说这和他的能力有关系"。

### 其余成员

具体信息尚无展开。

## 历史

- 主角从一开始就随本队活动，由城外进入柏格宁。

- 秦若孚彼时已在柏格宁独自发展；本队与秦若孚相遇后，队长为她起名“秦若孚”。

- 相遇后秦若孚入队，小队与秦若孚一同租住[柏格宁房东](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E6%9F%8F%E6%A0%BC%E5%AE%81%E6%88%BF%E4%B8%9C.md)的别墅，并持续向她“科普”法术、神明、科技共存社会的运作知识。

- 入城暂居：随队抵达[柏格宁](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E6%9F%8F%E6%A0%BC%E5%AE%81.md)后，租住[柏格宁房东](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E6%9F%8F%E6%A0%BC%E5%AE%81%E6%88%BF%E4%B8%9C.md)的别墅，约第三日入住，初期被交代“不要出门”。
