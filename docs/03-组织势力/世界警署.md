# 世界警署

[在 My Project 中编辑](https://chatgpt.com/space/page_66300a48aa8c819187e40695316f20cf)

世界警署是隶属于联合国的国际组织，向地方提供武装治安力量，支援当地治安管理。

## 柏格宁介入

世界警署将[柏格宁](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E6%9F%8F%E6%A0%BC%E5%AE%81.md)列为治安力量缺失区域，安排路易斯带队介入。当地警力在履职动机与实际能力上存在缺口，外来势力的活动进一步加剧治安压力。

路易斯根据管制药物黑市价格的异常浮动、成瘾人员数量扩大等数据，怀疑[毒魔教团](%E6%AF%92%E9%AD%94%E6%95%99%E5%9B%A2.md)正在当地开展有组织的活动。这一判断处于个人怀疑阶段，相关证据链仍在建立。他对当地分支的核心成员、落脚点和具体活动了解有限，教团流动的小型集会使持续追踪更加困难。

本土警力领导是地方治安负责人的下属，负责日常警务。巡查队由治安负责人直接管理，在现场安全、伤亡事件和异常线索等事务中与世界警署发生协作。

## 路易斯

路易斯来自毕格兰特洲，接受过良好的精英教育与军官教育，以少校军衔自愿加入世界警署。他具有较高的道德操守和职业操守，也重视自身生命与安全，将保全自身视为持续履职、维持地方稳定的条件。
