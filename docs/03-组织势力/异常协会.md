# 异常协会

[在 My Project 中编辑](https://chatgpt.com/space/page_b4d75112b8e48191a1dc48e7e2460a73)

异常协会是负责[险域与禁域](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E9%99%A9%E5%9F%9F%E4%B8%8E%E7%A6%81%E5%9F%9F.md)调查及档案管理的组织。1903 年，联合国授权其调查世界各地的禁域，要求成员国不得阻碍协会及其下辖组织的探查。

## 基本信息

| 项目 | 内容 |
|---|---|
| 性质 | 官方/国际授权机构 |
| 授权方 | 联合国 |
| 下属/分支 | 资料局、管理局、下辖组织/探查小组 |
| 关键成员 | 档案管理人员"奥菲" |
| 获授权时间 | 1903 年 |

## 宗旨与运作

- **合法性来源**：1903年联合国授权异常协会对世界各地禁域的调查权，决议通过之日起联合国全部成员国有义务不阻碍异常协会及其下辖组织对禁域的探查事务。
授权为探查提供合法性保障，但探查小组仍需处理与当地势力的纠纷。

- **档案制度**：一级险域须六十天内进行一次探查、且至少有一次探查记录才能长期定档；纸质档案定期核查以保时效，发现问题应立即上报并组织探查；报告在探查结束后撰写归档。

## 组织结构

- 出现过的内部名称：**异常协会**、**异常协会资料局**、**管理局**，三者关系指向同一体系（协会为组织总名，资料局为档案收藏单位，管理局为档案管理与核查单位）。

- **探查小组**：以编号命名，已知"五组#1898"；组员含未归队者（ZZ0381 深入探查未结束）。

## 历史

- 1903 年：获联合国授权。
协会从前机构接收过档案，其中包括约五年前建立的 ZZ0381 档案。
在[ZZ0381草原禁域](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/ZZ0381%E8%8D%89%E5%8E%9F%E7%A6%81%E5%9F%9F.md)的档案核查中，协会发现其长期按一级险域定档却没有探查记录，因而决定召开特别会议，提档为禁域并组织外围探查。

## 与其他势力的关系

异常协会与法术协会是不同组织，后者参与法术研究及相关社会事务，见[法术体系](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E6%B3%95%E6%9C%AF%E4%BD%93%E7%B3%BB.md)。
