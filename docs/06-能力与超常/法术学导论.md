# 法术学导论

《法术学导论》是介绍[法术](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E6%B3%95%E6%9C%AF%E4%BD%93%E7%B3%BB.md)的教材。现有残章为“第二讲 法术与心理健康”，讨论施法的精神反作用、长期施法者的精神健康统计，以及法术天赋与从业选择之间的关系。残章多处以省略号中断，内容并不完整。

## 法术与精神反作用

第二讲引用第一讲对法术的定义：

> 第一讲当中提到，法术是一种精神影响物质世界的一种现象，在精神对物质世界产生影响的同时，精神也会受到一定的反作用，包括但不限于，疲劳，思维减速，情绪波动等。……

讲义指出，长期施法会带来持续的心理影响，甚至涉及不同程度的精神疾病。

## 长期施法者调查

讲义引用了 1901 年国际法术协会的公开报告。在随机抽样的五十万名长期法术使用者中，约 60% 患有不同程度的精神疾病，其患病率超过几乎不接触法术人群的三倍。

讲义将这一现象与精神掌控能力联系起来：施法需要较强的精神掌控力，而这种能力在日常生活中可能妨碍情绪宣泄。具有这类特征的人又往往有较好的法术天赋，更倾向于成为法术从业者。
