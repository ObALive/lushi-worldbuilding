# 魔与法

[在 My Project 中编辑](https://chatgpt.com/space/page_c2facc9dae38819184880eba87d308ec)

“魔法”与“法术”指不同的力量。魔法专指与[神魔](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E7%A5%9E%E9%AD%94%E4%BD%93%E7%B3%BB.md)相关的力量，不能作为[法术](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E6%B3%95%E6%9C%AF%E4%BD%93%E7%B3%BB.md)的同义词；二者的用词习惯也有区别。

## 用词差异

“魔”是随着人类对自然与超自然的信仰而产生的古老词汇，通常指与神相对、以恐惧为生的存在。这个字的其他含义也多为负面，人们在日常遣词中对它有所避讳。

“法”同样是古老词汇，近代人类开始系统研究法术后，借用这个字描述相关事物，并形成一系列拓展词汇。

## 词汇替换表

| 秦若孚残留词库 | 本世界观用法 |
|---|---|
| 将魔法视为法术的同义词 | 二者并非同义词，称呼法术时使用“法术” |
| 魔术师 | 幻术师 |
| 魔力 | 法力 |
| 魔幻 | 奇幻、梦幻 |
| 魔咒 | 咒术 |

## 秦若孚的用词

[观](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E8%A7%82.md)在学习法术时，下意识将“魔法”当作法术的同义词，并在交流中使用。授课队长反问“魔法？那是什么？”，随后解释了“魔”与“法”的用法。

她又想到魔术、魔力、魔幻等词，发现它们与队长所讲的含义不同，因此开始疑惑自己脑中残存知识的来源。她没有继续追问，而是记下幻术师、法力、奇幻或梦幻、咒术等用词。
