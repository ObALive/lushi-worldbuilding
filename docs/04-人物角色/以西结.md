# 以西结

[在 My Project 中编辑](https://chatgpt.com/space/page_596191dd10748191adaf40e201eb00d4)

以西结是毒魔梅蒂欣的眷属，也是[毒魔教团](../03-%E7%BB%84%E7%BB%87%E5%8A%BF%E5%8A%9B/%E6%AF%92%E9%AD%94%E6%95%99%E5%9B%A2.md)中世代传承的代号。持有者在 21 岁后成为梅蒂欣降临的容器，主持教团的重要祭司活动；每代持有者于 28 岁死去，下一代同时诞生。

## 外貌

- 三对白翼：颅侧一对遮左目、背部一对飞翔、腰侧一对蔽足。

- 一对修长的山羊角，一双山羊眼。

- 淡灰的短发齐肩，鬓发稍长垂于胸口。

- 不穿鞋子；脖子挂系一个铜铃铛，手腕上戴着许多珠串，摇一摇就沙沙作响。

- 外观像是其两位童子（鸽童子+羯童子）外观的合体。

## 能力与设定

- 宗教容器设定：毒魔下属宗教组织中“始终有一个叫做以西结的角色”，通常为青年男性亚人种，罕见地混合鸽子与山羊两种物种外观；21 岁前始终蒙面，21 岁后成为梅蒂欣附身降临的容器，并主持教内一切重大祭司活动，21 岁前此任务由教内主祭承担。

- 世代更替：“每一代以西结都会在 28 岁死去，新一代的‘以西结’会同时诞生。”

- 修行流放：21 岁前在教内没有特殊地位，被要求修行。

## 关系

- 毒魔梅蒂欣：其“眷属”，附身降临的主神；“我”与“以西结”是两个概念，他口中的“我”指梅蒂欣的意志。

- 引路童子：21 岁前蒙面，由两个引路童子引路——鸽童子（雄性：净白的皮肤、黑色的卷发、三对白翼〔颅侧/背部/腰侧〕、及地的修长尾羽）与羯童子（雌性：褐色的皮肤、洁白的齐肩短垂发、细长的羊角、一双山羊眼）；都比以西结年长 3 岁；在以西结 21 岁接任祭司的成人礼上“会被杀死用于成人礼仪式”；二人被熏哑喉咙不能言语，“忠诚地扮演着工具的角色”；平时以西结用背上双翼拢住二位童子引路。

## 轶事

### “我不是以西结”

- 他自称时从来不用“我”，一直以“以西结”自称；在他看来“我”和“以西结”是两个概念。

- 蒙面遮目理由：只有在梅蒂欣降临在他身上时才会移开遮目的双翼；教内规训——“眼睛是心灵的窗户”，降临前不得以外物景观污染躯体，“因为这幅躯体是毒魔的所有物，而他只是类似于寄居蟹的存在。于是，他也就没有自称‘我’的资格”。

### 教团眼线与历练

- 毒魔教团在许多能够对世界格局产生影响的组织内都布有眼线，甚至直接掌控这些组织的一部分。

- 以西结会被以各种身份送往教团有足够掌控力的地方，以教团给定的身份生活一些时日（历练/潜伏语境）。

- 每个宗教都有圣器；以西结就是这个宗教最重要的人形圣器，本身受到神的关注和庇护，也受到教团明里暗里（主要是暗里）的重重保护。

## 考据

以西结的世代传承机制借鉴了藏传佛教的转世观念。
