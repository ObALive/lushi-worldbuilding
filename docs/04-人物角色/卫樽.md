# 卫樽

[在 My Project 中编辑](https://chatgpt.com/space/page_6e785e2662208191b0b0e7b09a981f72)

卫樽是[魏淳](%E9%AD%8F%E6%B7%B3.md)在另一具肉体中重生后使用的身份。他以新的身份继续校园生活，其身体与一位古代神的复活有关。

## 外貌

- 右脸腮帮有一块黑色的类似纹身的纹路：下部形似匕首，上部形似海浪。

- 比较蓬松的黑发，发梢红色；红色部分的多少和鲜艳程度取决于当前汲血量的多少。

- 常年当“守纪学生”让他对这个发质多少有些不自在，“虽然没啥差别，但是有兜帽的时候戴上会更有安全感”。

## 能力与设定

- “神的胚胎”。

- 新躯体对魔法有可以用“共生”一词来形容的契合度，外貌与以往截然不同。

- 依小说情节尝试寻找意识深处苏醒的“什么危险存在”，到目前为止没有任何发现。

- 死后的魏淳完全独立地以更强大的躯体重生了，此时的他，还需要很长一段时间才能知道这是成神的第二步。

## 经历

- 少年魏淳接触黑魔法之后，给自己造的第一个身份即卫樽。

- 在对黑魔法私下的研究当中因“发生意外”而在校内死亡；在下葬安顿的事情简单而没有引起任何波动的情况下办完了。

- 葬礼结束后的三天，魏淳的意识猛然睁眼，发现自己在一具完全不同的身体里，躺在学校的花坛深处醒来。

## 关系

卫樽与魏淳拥有同一意识，使用不同的身体与身份。

### 肉体与复活

- 魏淳与卫樽是两具不同的肉体：魏淳死后，其意识在另一具肉体上重生，并给自己重新取名为卫樽。

- 卫樽并未继续以魏淳的身份在学校生活，而是以新的（捏造的）身份继续校园生活；卫樽躯体的由来目前是谜团。
魏淳学习的魔法书来自一个已覆灭的古代宗教。学习过程中，他的灵魂与[神之遗躯](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E7%A5%9E%E9%AD%94%E4%BD%93%E7%B3%BB.md)的契合度越来越高。

- 其死亡是该覆灭宗教之神设计的关键复活步骤：魏淳杀死自己的肉体，使灵魂能够被神之遗躯获取——精通这些魔法的灵魂，正满足这位古代神以弱小姿态复活的条件。
