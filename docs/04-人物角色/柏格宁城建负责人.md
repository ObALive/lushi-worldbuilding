# 柏格宁城建负责人

[在 My Project 中编辑](https://chatgpt.com/space/page_da1976547da48191874181adcfb27bc3)

柏格宁城建负责人是一名战后留在[柏格宁](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E6%9F%8F%E6%A0%BC%E5%AE%81.md)的军官，负责桥城建设相关的专项事务。他希望积累足够的钱，回到家人身边，在安逸的地方养老，并利用手中的工程与项目谋利。

## 经历

战争期间，他与其他军官因守城局势陷入绝望而上山求助[西格露恩](%E8%A5%BF%E6%A0%BC%E9%9C%B2%E6%81%A9.md)。求神途中，军官们围绕赐予的物品争夺、设局，接连出现死亡。他与另一名军官离山返回部队。

战后，他留任当地，参与城市建设。大桥工程最初以应付验收、侵吞工程款为目的；[赫拉尔伯敏](%E8%B5%AB%E6%8B%89%E5%B0%94%E4%BC%AF%E6%95%8F.md)以材料学天才的身份提供特殊建筑材料后，工程规模扩大，发展为承载新区与城市中心的桥城。

## 工程与异常处置

他和建桥核心参与者掌握各自接触的工程内幕，对材料与持续异常之间的关系产生联想和猜测。地方治安负责人组织巡查队承担日常异常处置，双方需要就清理费用、现场配合与事故责任协调。
