# 梅蒂欣

[在 My Project 中编辑](https://chatgpt.com/space/page_20c8bd2b8d2881918ab83688b5c317ab)

梅蒂欣是掌握毒之权柄的[魔](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E7%A5%9E%E9%AD%94%E4%BD%93%E7%B3%BB.md)，也是[毒魔教团](../03-%E7%BB%84%E7%BB%87%E5%8A%BF%E5%8A%9B/%E6%AF%92%E9%AD%94%E6%95%99%E5%9B%A2.md)崇奉的对象。她以恐惧获得供养，通过扩大势力和增强力量寻找返回故乡的方法。

## 权柄与影响

毒是梅蒂欣的权柄。千百年间，传统毒物带来的影响逐渐式微。进入现代后，她转向成瘾性管制药物，以此扩大自身影响，其效果超过了传统毒物。教团的药物经营与势力扩张服务于这一方向。

## 归乡愿望

梅蒂欣思念风见幽香，积极寻找返回故乡的出路。她将势力扩张与力量积累视为寻找归路的手段，并持续推动教团扩大活动范围。

## 降临与教团

[以西结](%E4%BB%A5%E8%A5%BF%E7%BB%93.md)是梅蒂欣的眷属和降临容器，在教团中作为人形圣器受到保护。世代更替的容器承担她在教团中的降临及重要祭仪。
