# 观

[在 My Project 中编辑](https://chatgpt.com/space/page_526754822070819185c1c7fcc82b7496)

观是“陆拾肆”企划中对应观卦的剑灵，也是柏格宁线的主要视角角色。她失忆后在[柏格宁](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E6%9F%8F%E6%A0%BC%E5%AE%81.md)老城区苏醒，凭借感知他人情绪与意图的能力接取委托，以“报童”之名活动，后来加入[赫拉小队](../03-%E7%BB%84%E7%BB%87%E5%8A%BF%E5%8A%9B/%E8%B5%AB%E6%8B%89%E5%B0%8F%E9%98%9F.md)，获名秦若孚。

## 外貌

目视14—16岁的犬亚人少女，身形纤细，浅金色头发、灰蓝色眼睛与一对尖立的犬耳构成主要外貌特征。性格敏锐、好学，对陌生事物有求知欲，社会经验尚浅，遇到危险时能够主动观察并寻找脱身机会。设计以日式幻想冒险为基础，融合复古旅行服饰与现代实用配件。她对周围的人与事保持关注，会认真揣摩他人的言行，也会因缺少常识而流露疑惑；整体气质年轻、机敏，带着初涉世事的生涩。

作为犬亚人，她的兽化程度为 II 级。

- 体貌与发色：少女外貌。头发呈浅金至米白色，前侧发束垂至肩部，后侧略长，刘海分束，头顶有一撮翘起的发丝。头顶生有一对犬形兽耳，耳内覆有浅色绒毛，灰蓝色虹膜。

- 上身服饰：内穿白色短衬衣，外罩敞襟的浅驼色长外套。外套腰部略收，衣摆向下展开，长度及膝；袖口翻折，衣身设有口袋、纽扣及棕色皮革饰带。

- 下身与鞋履：穿深棕色短裤，腰间系有带金属扣的皮带，另有皮革束带及腿环。双腿采用不对称搭配，一侧露腿，另一侧穿浅色长袜。脚穿深棕色长筒系带靴，靴口配有较宽的皮革扣带。

- 手套与配饰：双手戴深色露指手套，颈前挂着一副圆镜片护目镜。棕色挎包的宽肩带斜跨胸前，包体较大，垂在胯侧。

- 随身装备：携带带有皮革固定结构的剑，以及一盏细长的框架式提灯。提灯上下设有圆形底座与顶盖，灯身以交叉支架围护，内部呈暖橙色。
整体以浅驼、米白和深棕为主色，皮带、挎包、长靴与提灯构成了鲜明的旅行者装束。

## 能力

她的能力表现为看见「丝线」——从他人身上涌出的细线状显现，能够借此察知对方当下的情绪与意图。这一感知在遇到情绪特别浓烈的人时最为清晰，此时的丝线不仅可见，还带有颜色。丝线的感知并不依赖视觉，即使闭上眼睛也能察觉，因此它更接近一种直接的体感而非影像式的观察。

对丝线的判读出于本能，而非学习所得。用她自己的说法，这就像眼睛看到红色时就知道那是红色，不需要经过判断的过程。就现有材料看，这种感知似乎只有她自己能够察觉，旁人无从知晓她看见了什么。

在用途上，她把这种能力用于察言观色、辨明谎言，以及找到有意躲藏起来的人。她在以赏金委托谋生的那段时间里，正是依靠这种能力获得优势。

她当前的能力称为“意图之丝”，属于读心能力的初级形态。

## 关系

她在苏醒后先帮助了[何守](%E4%BD%95%E5%AE%88.md)，与他相识后开始在其私人办事所接取委托。两人的关系近似临时雇工；何守同时是[毒魔教团](../03-%E7%BB%84%E7%BB%87%E5%8A%BF%E5%8A%9B/%E6%AF%92%E9%AD%94%E6%95%99%E5%9B%A2.md)在当地的线人。

「秦若孚」这个名字出自[赫拉小队](../03-%E7%BB%84%E7%BB%87%E5%8A%BF%E5%8A%9B/%E8%B5%AB%E6%8B%89%E5%B0%8F%E9%98%9F.md)的队长。小队成员另有邘陇、潘、狄俄斯等人。

她与[主角](%E4%B8%BB%E8%A7%92.md)的关系是这组设定中最紧密的一环。主角是周文王轮回体的男性故事主角，身世与观彼此相连；在故事的时间线上，主角从一开始便随行脚商小队从城外进入柏格宁，最后与独自在此发展的观相遇。两人的相遇构成了柏格宁线开局的分水岭。

[柏格宁房东](%E6%9F%8F%E6%A0%BC%E5%AE%81%E6%88%BF%E4%B8%9C.md)是她入队之后的居处主人——相遇之后，她与小队一同租住在房东的别墅里。

[盖维小队](../03-%E7%BB%84%E7%BB%87%E5%8A%BF%E5%8A%9B/%E7%9B%96%E7%BB%B4%E5%B0%8F%E9%98%9F.md)的柏格宁分队曾调查“报童”的活动，并在废弃商场事件中为她提供狙击掩护。

## 经历

她在柏格宁老城区苏醒时，失去了过往经历与绝大部分知识，只保留日常生活所需的常识。她依稀记得失去意识前曾尝试用笔录保存记忆，但记录被某种力量销毁；她似乎还喊过“哥哥”，却无法确定对方的身份及其与失忆的关系。铁匠曾用五天尝试修复她携带的断剑，最终未能成功。

苏醒之后，她独自在柏格宁生活了一段时间，以谋生和寻找身世线索为目标，运用感知他人情绪与意图的能力换取报酬。她在何守的办事所接取各类委托，逐步在当地积攒起知名度，并获得了「报童」这个外号。她自我介绍时也用这个名字，以致旁人误以为她在隐姓埋名。她在工作中接触不同的人与势力，自身的能力及剑灵特质又使她逐渐卷入更多事件。

与此同时，主角随行脚商小队从城外进入柏格宁。随着两人物理距离缩短，观的能力逐渐增强。

何守向毒魔教团上报了“报童”的情况。教团通过线人几日的观察确认她确实失忆，看中她的实力和认识上的可塑性，希望将其吸纳并向她灌输有利于“毒”的观念。何守随后与教团设计委托，将她引到偏僻的废弃商场。教团准备在招揽失败后将她清除。她假意同意并寻找逃跑机会，在困境中发现断剑已经自行拼合，随后首次杀人，并在盖维小队的狙击掩护下寻找出口。主角受队长委托，带着法术物品进入商场，将她带离险境。

获救后她加入赫拉小队，队长为她取名秦若孚。她与小队一同租住柏格宁房东的别墅，学习法术、神明与科技并存的社会如何运作。何守的办事所后来被转让，何守本人失踪。

商场冲突使她成为教团的清除目标。教团将她表现出的敌意、实力以及对当地活动的了解，视为维持隐秘性时需要处理的风险。

主线继续展开的部分包括：她与主角一同学习「白道黑道」的生存方式；一封匿名信带来存储卡，其中存有卧室俯拍、刻纹弹药与无人机追逃的视频，指向「黑货贩子」；以及市中心大桥的「亡灵生物清理委托」，其中出现了封闭车厢进出与 GPS 失灵的异常。

## 轶事

### 名字的由来

「若孚」取自《周易》观卦卦辞「观：盥而不荐，有孚颙若」，将「若」与「孚」重组为名，取诚敬、信实之意，与她对应观卦的剑灵身份相联系。

队长尚未向她说明「秦」姓的深层含义，只告诉她往后自然会懂。
