# 赫拉尔伯敏

[在 My Project 中编辑](https://chatgpt.com/space/page_403e7b6c0aa88191adc7109b8a92130e)

**概述**：一位将在剧情很长一段时间里以神秘隐藏角色登场的存在。他的出现往往伴随着悲剧的影子与由头：他似乎有意在世界各处行迹、制造灾难、埋下悲剧的种子——手法并非以特殊能力操盘，而是在关键时刻为关键角色提供一些关键物品或情报，使整个事件朝悲剧方向发展。他行事的动机目前是一个谜团。

## 外貌

- 最显著特征：一双**白色的眼睛**——从瞳孔到虹膜全都是白色。无论他扮演什么角色，唯独这双眼睛的特征无法改变。

## 已知出场

- 为艾米丽提供“危机即将降临”的预言。

- 在危机结束后，告诉艾米丽“复活珍视之人的方法”。

- 在[白萨尼斯](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E7%99%BD%E8%90%A8%E5%B0%BC%E6%96%AF.md)医院门口，以算命先生的模样向独自出行的首相提供建议。

- 在[柏格宁](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E6%9F%8F%E6%A0%BC%E5%AE%81.md)建设之初，以失意的材料学天才身份向[柏格宁城建负责人](%E6%9F%8F%E6%A0%BC%E5%AE%81%E5%9F%8E%E5%BB%BA%E8%B4%9F%E8%B4%A3%E4%BA%BA.md)提供一种短期性能很强、超过一定期限后迅速老化的建筑材料。

## 考据

角色设定部分参照了 Minecraft 都市传说中的 Herobrine。
