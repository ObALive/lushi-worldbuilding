# 行脚商

[在 My Project 中编辑](https://chatgpt.com/space/page_deab315236a08191b554e4bb9fb4d700)

行脚商是往来各地贩运货物、采集稀有材料的流动商人，也兼营情报交易、承接委托和交付悬赏。

## 小队与货源

行脚商一般结成小队，成员以[天生施法者](%E6%B3%95%E6%9C%AF%E4%BD%93%E7%B3%BB.md)为主。人数少，组织和维持队伍的开销较低，成员的法术能力又使小队有足够的自卫能力，能够亲赴危险产地取材，并把零散货物运往远方。

## 材料贸易与行业处境

行脚商一部分货物购自他人，相当一部分由成员亲自在野外猎取。自然场流微弱的平凡之地缺少本地特有的法术材料，其他地区出产的材料仍可由行脚商跨区运送。

来自神学家和法术学家的订单有时只需要少量材料，而产地远在另一片大陆。货量小、路途远且沿途危险，这类买卖尤其适合由能自行护送货物的小队承接。

长途贸易也依赖同行长期形成的默契。小队往来于不同地区，要与其他行脚商维持合作关系。

近代贸易公司的兴起挤压了行脚商的市场。许多发达国家又将行脚商纳入对流动小型武装的管制，限制了他们的活动。
