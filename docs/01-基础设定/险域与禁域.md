# 险域与禁域

[在 My Project 中编辑](https://chatgpt.com/space/page_3371482dc560819185adfe21a28c3085)

**概述**：险域是指对常人而言具有危险性、禁止常人涉足的区域，按照危险程度划分为一至五级，其中一级险域最为危险。禁域则是比一级险域更为特殊的存在，指那些超出经典科学解释范畴、异常事件频繁发生的地带，其危险性与特殊性均远超常规险域。
险域与禁域均由获得授权的国际机构——异常协会——负责统一建档、危险分级与调查探查，以规范相关区域的管理，并为后续调查与风险评估提供依据。

## 定义

险域是指对常人而言具有危险性，且通常禁止常人涉足的区域。

禁域则是超越经典科学解释范畴的异常事件频发之地。与险域主要依据区域的危险性进行界定不同，**禁域的定义核心在于引发异常现象的那股力量，而非某个边界分明的地理区域**。由于这股力量的作用过程难以控制、运行原理尚不明晰，其存在及影响始终是社会体系中的不安定因素。

禁域在世界各地均有分布，其形态与影响范围各不相同。它们在当地社会文化中长期被视为禁止涉足的区域，实际影响范围未必与人们认知中的区域边界完全重合。

## 规则/细节

险域分为 1–5 级，数字越小，危险程度越高；禁域的危险程度则高于一级险域。为确保分级结果的准确性与时效性，异常协会建立了相应的档案管理与探查制度。

其中，一级险域必须在 60 天内至少接受一次探查，且须具备至少一份探查记录，方可长期定档为一级险域。

此外，纸质档案须定期核查，以确保档案内容与实际情况相符。核查过程中一旦发现问题，核查人员必须立即上报并组织一次险域探查行动，不得拖延。

每次探查结束后，相关人员方可撰写探查报告并提交归档，由异常协会资料局统一收纳档案并进行编号。

1903 年，联合国通过决议，授权异常协会调查世界各地的禁域。自决议通过之日起，联合国所有成员国均有义务不得阻碍异常协会及其下辖组织开展禁域探查工作。这项授权为异常协会的禁域探查提供了国际法层面的合法性保障，但其效力仅限于此，并不意味着探查行动能够免受现实阻碍。因此，在实际任务中，探查小组不仅要应对禁域内部的未知威胁，还必须处理与当地势力之间的纠纷，协调各方关系，才能推进探查工作的开展。
