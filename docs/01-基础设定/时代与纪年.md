# 时代与纪年

[在 My Project 中编辑](https://chatgpt.com/space/page_42b1cc3b3e2c8191a282340037cc34c7)

本世界观经历过三次世界大战，其中第三次世界大战称为[法术革命](../05-%E5%8E%86%E5%8F%B2%E4%BA%8B%E4%BB%B6/%E6%B3%95%E6%9C%AF%E9%9D%A9%E5%91%BD.md)。第二次世界大战后，法术开始得到系统研究；第三次世界大战结束后，法术正式进入大众视野。

## 相对年代

第一次世界大战期间，悬丝之王·埃尔托萨曾活跃于世。[白萨尼斯](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E7%99%BD%E8%90%A8%E5%B0%BC%E6%96%AF.md)在法术革命后成为商业都会。

[ZZ0381草原禁域](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/ZZ0381%E8%8D%89%E5%8E%9F%E7%A6%81%E5%9F%9F.md)周边的异常记录可追溯千余年，其提档核查发生在档案建立约五年后。[柏格宁房东](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E6%9F%8F%E6%A0%BC%E5%AE%81%E6%88%BF%E4%B8%9C.md)在数年前结束的世界大战中失去双亲，得到别墅作为战后补偿。这些事件没有明确的绝对年份。

## 作者谈

世界观的时间线大致参照现实历史，但年份不代表同一技术水平。设定中的 1900 年大致对应现实中的 2200 年，生活方式接近现实现代，并穿插对未来科技的想象。科技发展受自然资源的制约较少，具体年份仅提供参考范围。

第一次和第二次世界大战分别参照现实的一战和二战，并加入奇幻因素。联合国借鉴现实组织的原型，设有法术相关部门，属于本世界观中的独立虚构组织。
