# 神魔体系

[在 My Project 中编辑](https://chatgpt.com/space/page_64399b4ed61481918b03961eea9f3900)

神与魔是同一类精神体生物，以信仰与恐惧为食物和力量来源。它们能够为获取供养而塑造对立形象、引发纷争。与神魔相关的特殊力量称为魔法，与[法术](%E6%B3%95%E6%9C%AF%E4%BD%93%E7%B3%BB.md)分别形成不同的力量体系。

## 定义

神与魔以精神体的形式存在，依靠人类及其他生物产生的信仰与恐惧维持生存、积累力量。

“神”与“魔”的称呼源于人类在历史中对这些生物形成的不同认识。为了获取更多的信仰与恐惧，它们会主动塑造彼此对立的形象，甚至通过制造纷争来强化这种关系，从中获得供养。这种对立在很大程度上服务于其生存需求。

神与魔的力量取决于其所吸收的信仰或恐惧的数量。随着积累不断增加，它们会逐渐成长，并最终获得直接影响物质世界的能力，例如降临到其他生物身上，或直接创造一副属于自己的身体。对于尚未达到这一程度的神与魔而言，物质世界中的活动受到较大限制；而一旦具备了创造自身身体的能力，它们便拥有了更为直接地介入物质世界的途径。

通常情况下，神与魔一旦失去信仰与恐惧的供养，即失去信徒，便会走向死亡。这里的死亡意味着其精神存在彻底消散，不会以原有的形式继续存续。不过，对于曾经达到创造自身身体这一力量层次的神与魔，存在一种特殊情况，即所谓的**“神之遗躯”**。这类存在死亡后，其超自然力量会随之丧失，但意识与记忆仍然保留在曾经创造的躯体之中，使其能够以普通人的身份继续生活。

随着人们对神与魔的认识不断深入，一些宗教影响力较弱的地区逐渐出现了另一种世俗论调：神与魔本质上只是寄生生物，与社会文化中自然形成的崇拜图腾并非同一种存在。按照这一观点，神与魔并非信仰所指向的文化象征本身，而是借助人类既有的精神文化体系，将自身伪装成其中的神圣象征，并以此获取信仰与恐惧作为生存所需的养分。
