# 法术体系

[在 My Project 中编辑](https://chatgpt.com/space/page_f5f85d53730481918ab23fda1151c7b1)

法术是通过精神力量改变物质世界的一类现象。施法伴随着精神消耗，其流派按照施法方式划分，与[神魔](%E7%A5%9E%E9%AD%94%E4%BD%93%E7%B3%BB.md)相关的魔法属于不同力量。

## 定义

[《法术学导论》](../06-%E8%83%BD%E5%8A%9B%E4%B8%8E%E8%B6%85%E5%B8%B8/%E6%B3%95%E6%9C%AF%E5%AD%A6%E5%AF%BC%E8%AE%BA.md)将法术定义为一种精神影响物质世界的现象。在这一过程中，精神不仅能够对物质世界产生影响，也会受到相应的反作用，包括但不限于疲劳、思维减速与情绪波动等。

从纯粹的物理层面观测，法术会在封闭系统中产生熵减行为；将精神层面纳入观测，则可发现法术的释放伴随着精神消耗。

法术的释放依赖施法者自身的精神能力，其施展过程中的所有步骤均需要人的参与，无法完全脱离个体独立完成。由于不同个体的精神能力存在差异，即使施展相同的法术，其具体过程与最终效果也可能呈现出不同程度的特异性。

**这一特性从根本上限制了法术生产的标准化与规模化。** 与传统科技生产依靠工具、机械与流水线实现人力替代和流程标准化的模式不同，法术的施展始终受到施法者个人能力与状态的影响，难以实现对人力的完全替代，也难以直接套用传统工业生产中的流水线模式。

## 历史背景

第二次世界大战后，法术逐渐得到系统研究。第三次世界大战即[法术革命](../05-%E5%8E%86%E5%8F%B2%E4%BA%8B%E4%BB%B6/%E6%B3%95%E6%9C%AF%E9%9D%A9%E5%91%BD.md)，法术协会诞生于革命之初。革命结束后，法术正式进入大众视野并得到社会接纳。纪年背景见[时代与纪年](%E6%97%B6%E4%BB%A3%E4%B8%8E%E7%BA%AA%E5%B9%B4.md)。

## 学派分类

法术原料依学派天差地别，但都是来源于自然界当中本身有着一定程度超自然力量的事物；法术的学派主要依照施法方式来定义，施法的方式有着很强的地域特征，施法的效果方面各有所长。

流派的根本区别在于精神转化为物质能量的方式，而非最终效果。不同施法方式各有适用范围与局限，实现某一效果的难易程度也随之改变。亡灵法术等名称描述的是施法效果，与下列施法方式不构成并列分类。表中列举的是四种流派，并非全部流派。

| 学派 | 施法方式/特征 |
|---|---|
| 花药法术 | 通过特殊植物炼药 |
| 符文法术 | 通过特殊刻纹引导能量 |
| 工具附魔 | 通过仪式将经卷中的内容注入物品 |
| 矿物法术 | 组合原矿水晶等天然矿产 |

## 法术场流

法术场流描述区域法术环境的强度，可由设备观测计量。在[险域与禁域](%E9%99%A9%E5%9F%9F%E4%B8%8E%E7%A6%81%E5%9F%9F.md)的探查中，当测量目标或运行环境的关键参数远超设备额定值时，设备会出现被称为“过敏状态”的异常。法术相关设备在场流极高时还可能无法关闭。

## 用词与禁忌

“魔法”专指与神和魔有关的特殊力量，不能作为法术的同义词。“魔”是一个古老词汇，通常指以恐惧为生、被视为与神对立的存在；人们在日常表达中对这个字有所避讳。

“法”字在近代法术研究兴起后，被借用于描述相关事物，并衍生出相应的词汇体系。法术侧使用幻术师、法力、奇幻或梦幻、咒术等称呼。具体用词见[魔与法](../06-%E8%83%BD%E5%8A%9B%E4%B8%8E%E8%B6%85%E5%B8%B8/%E9%AD%94%E4%B8%8E%E6%B3%95.md)。

## 施法者的精神健康代价

1901 年，国际法术协会在其公开报告中指出，在随机抽样调查的五十万名长期法术使用者中，患有不同程度精神疾病者约占总人数的 60%，其患病率超过几乎不接触法术人群的三倍。这一调查结果揭示了长期使用法术与精神健康问题之间的显著关联，但二者之间的具体因果关系仍需进一步考察。

这一现象存在着复杂的成因悖论。一方面，法术的施展要求使用者具备较强的精神掌控能力，能够主动约束和调节自身的精神活动。然而，这种能力在日常生活中可能产生负面影响：对精神活动的过度控制往往会抑制情绪的自然表达与宣泄，长期积累之下，反而可能增加精神疾病的患病风险。另一方面，法术天赋较为优秀的人更倾向于选择法术作为职业，并长期从事相关活动。因此，长期法术使用者本身就可能是一个经过筛选的特殊群体，其精神健康状况未必能够代表普通人群。这种由个体特征影响职业选择，进而影响统计结果的现象，构成了明显的自选择偏置。

由此可见，长期法术使用者较高的精神疾病患病率，既可能与法术施展对精神的要求及其产生的反作用有关，也可能受到从业者自我选择机制的影响。**法术使用与精神疾病之间的关联，尚且不能简单地归结为法术对精神的直接损害。**

## 法术协会

法术协会参与法术研究及相关社会事务，设有管辖地区。1888—1889 年间，协会不断证实古籍中的记载及其内在机理，动摇了传统科学的解释体系。1901 年的长期施法者调查报告由国际法术协会发布。

[异常协会](../03-%E7%BB%84%E7%BB%87%E5%8A%BF%E5%8A%9B/%E5%BC%82%E5%B8%B8%E5%8D%8F%E4%BC%9A.md)是负责险域与禁域调查的另一组织。

## 天生施法者

法术能力者，又称天生施法者，是一种特殊的法术使用者。与需要通过后天学习掌握特定释放方式的施法者不同，法术能力者天生便具备一种独特的施法方式，无须经过专门学习即可使用法术。从机制上看，他们仿佛先天拥有某种特殊的“法术器官”。这种器官并非物质意义上的实体，而是存在于精神层面的特殊结构，无法通过常规感官直接观察。法术能力者能够凭借自身感官与本能，直接通过这一特殊结构释放法术，其施法机制因而与其他法术使用方式存在根本区别。
