[在 My Project 中编辑](https://chatgpt.com/space/page_e051792c256c8191939b37ff4d84e838)

本页是全库的**命名总账**：决定每个实体的“规范名”（=文件名与链接名），登记一切别名/异写，保证跨来源内容合并且链接稳定。

- v0.0.1：首次建表（异写并列）。

- v0.0.2：按作者答复（`Task/对v0.0.1的问题解释`）归一。

- **v0.0.3（当前）**：按 `Task/v0.0.2对清单的答复.md` 与 `append/` 设定补充继续归一（艾米丽正名、菈比=od 合一、企划暂名陆拾肆、魔法/法术词义、约稿字段清除等）。✅ = 已定案。

- **v0.0.3+（003 标题规范，2026-10-02）**：按 `Task/003-角色标题规范问题.md` 清理角色页题中的括号。规则优先度＝①有本名用本名 ②否则取第一个别名 ③都没有则删括号。据本总账裁定，多数条目的括号内均为别名或说明，落规则③；**本名明确的三个条目改以本名为规范名**：缇尔莉斯（原苍翠隼影）、拜尔丹·卡兹米娅（原深黑祷者）、余散（原雨空和伞）——旧名降为别名，文件名、`title`、全库入链、总索引同步更新。同时按 5.2.5 清理了 13 个条目 `aliases` 中的 tag 名、来源路径与开发注记（纯名保留，注记内容以「词条历史」为归宿）。

## 规则

1. 规范名优先取：作者最新答复口径 > 最新稿用名 > 多来源同用名 > 语义最准名。未决并列标“待定”，登记[待决问题与冲突清单](%E5%BE%85%E5%86%B3%E9%97%AE%E9%A2%98%E4%B8%8E%E5%86%B2%E7%AA%81%E6%B8%85%E5%8D%95.md)。

2. 正文一律用规范名；必要的别名自然融入叙述，纯名记入 `aliases`，异写与命名沿革在本表留痕，不要求条目附加“词条历史”；raw 原文永不改动。

3. 文件名 = 规范名；改名时同步更新链接与总索引。

4. 读者向正文不出现来源路径、内部编号、约稿字段等编务信息；必要记录保存在 `meta/` 或任务报告，不建立 `_Dev` 副本，不将编务记录转移到“考据”“作者谈”。本规则按 2026-10-16 手改要求同步，详见[文档维护规则](%E6%96%87%E6%A1%A3%E7%BB%B4%E6%8A%A4%E8%A7%84%E5%88%99.md)。
