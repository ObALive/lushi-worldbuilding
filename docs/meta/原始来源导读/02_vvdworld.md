## 四、「黑线 / 意图之丝」能力规则汇总（本文件内可提取的全部机制）

1. **形态**：他人身上溢出、延伸入主角视野的丝线；恶意时为**黑线**，其余强烈情绪亦有丝线且带颜色（如「劫后余生后怕」的淡色）。

2. **感知本质非视觉**：闭眼也能感到丝线「存在于视野之中」——更像直感/心眼。

3. **判定本能化**：读出恶意「完全是一种感官的本能」，如同见红色知为红色。

4. **触发条件**：情绪「特别浓烈」时丝线才浮现（page6）。

5. **独占性**：只有主角能察觉；连见惯特殊能力者的办事所主也称「能直接看到别人意图的几乎没有」。

6. **用途（作者列举）**：察言观色、辨明谎言、搜寻躲藏的人；更多应用仍待验证。

7. **未写明限制**：距离、精度、能否被反制、丝线淡去的速度与含义等均未定义（page5 可见「后怕」丝线在谈话中逐渐淡去）。
