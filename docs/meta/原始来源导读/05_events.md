## 全局观察

### 1. 库的整体性质

「事件块」库既不是成稿连载、也不是正式设定集，而是**按"写作素材块"粒度归档的叙事/设定混合片段池**，服务于同一中文原创世界观（metree 体系）的长篇写作。证据：①同一主线情节被切成许多"第X天/第X个编号"的独立块（隐约的记忆 No.0001 → 鲜红如燃烧的欲望 第3天 → 黑色的挎包 第13/15天），块与块靠"前置：××"与 Tags 松散串接；②标题大量取自对白台词、道具或关键词（"请问有什么工作吗！"、《公民宪法》、美工刀、黑色的挎包、金属姓名牌、观），而非章节名，是"写作点子卡"命名习惯；③相当数量条目是未完断片（句子中途截断、只余标题/一句对白），说明很多块是"待续草稿"或从大稿中摘出的场景卡。CSV 无排序/章节/时间线字段，仅 Tags（周·其一）一种组织维度，佐证其为素材库而非连载目录。
