# Falcon-1780-DM

[在 My Project 中编辑](https://chatgpt.com/space/page_1bb71c32fe8c819193ce6e00c5899c82)

Falcon-1780-DM 是一款用于反器材作战的重型狙击步枪，由[缇尔莉斯](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E7%BC%87%E5%B0%94%E8%8E%89%E6%96%AF.md)使用。全枪长近两米、重近 30 千克，可使用定制弹药，并在固定后进行三连射。

## 外观与描述

- "极其强悍的Falcon（隼）狙击步枪"，最初设计时"弹仓仅有两发子弹的容量"；经扩容改造：增加更多皮卡汀尼导轨、枪管加粗、机构强度增强，"用于发射更加凶悍的特种反器材子弹"。

- 全枪长接近两米，重量近 30kg，"一般人根本用不了"。

## 功能与规则

- 弹仓理念（设计人员语）："狙击步枪一般只有一次射击机会，第2发弹是留作备用应急的。"

- 消音器："可以加装消音器，不过对于这种野兽级别的枪来说消音器的作用只能是让枪声听起来像别的声音。"

- 连射能力：配合底座支架使用、妥善固定后可进行三连射，"不过连射容易造成枪管和底座支架的损坏"。

- 弹药定制："子弹也是定制的，可以自行控制装药量来调控威力和动静，弹头也有多种款式可以选择。"

- 威力表述（设计师语）：“弹道上的一切都会被摧毁，这可是材料科学的巅峰”（其自注为：“显然被摧毁的不只是弹道上的一切”）。

## 使用

缇尔莉斯乔装为油画家时，将这支枪藏在画具箱内。
