# 维护方式

- 新增和修改 Wiki 资料时，直接更新本空间相应条目。

- 保留原文的设定口径、草稿状态和正典性；迁移不等于确认存疑设定。

- 关系变化时，同时更新来源页链接、目标页反向引用和内容关系索引。标签、别名和状态变化时，同步更新相应索引。

- 编务文档中的旧目录路径与代码示例保留为历史上下文，不作为默认回写本地文件或重新导入 Notion 的指示。
