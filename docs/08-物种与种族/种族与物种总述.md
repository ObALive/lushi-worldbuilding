# 种族与物种总述

[在 My Project 中编辑](https://chatgpt.com/space/page_d384a6ecca9c81918acda033a5354188)

本世界观存在人类与大量具有动物特征的亚人种。亚人种保留动物特征的程度各不相同，可以从完全的人类形态到完全的动物形态划分为五级。

## 亚人种

亚人种的身体兼有人类与动物的特征。兽化程度较低者只保留耳朵、尾巴等少量动物器官；程度较高者保留大部分动物器官与皮肤，同时可能具备直立行走和使用人类语言的能力。

### 蝴蝶亚人

蝴蝶亚人的触角是感受器官，触角被折断意味着心智的折损。

## 亚人种「兽化程度」五级

兽化程度按生物特征大致分为五级。

| 等级 | 说明                                                                                             |
| ---- | ------------------------------------------------------------------------------------------------ |
| 1    | 完全的人类                                                                                       |
| 2    | 保留很少的动物特征：只有耳朵、尾巴等少量动物特征保留，皮肤全部为人类皮肤                         |
| 3    | 拥有与人类相近的骨骼结构：基本依靠双足直立行走，保留一部分特征显著的动物器官，保留小部分动物皮肤 |
| 4    | 有少量的人类体态特征：能够直立行走、能够使用人类语言，保留绝大部分原始动物器官，皮肤几乎没有变化 |
| 5    | 完全的动物                                                                                       |
