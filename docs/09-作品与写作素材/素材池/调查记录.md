# 调查记录

[在 My Project 中编辑](https://chatgpt.com/space/page_1a7601c46770819199c1c75b76e893f9)

《调查记录》是禁域例行调查的档案体通讯记录，收录五队与终端记录员之间的两次通讯，编号为 03833、03834。两节均以对白收束，相关图像见[充满噪点的图片](%E5%85%85%E6%BB%A1%E5%99%AA%E7%82%B9%E7%9A%84%E5%9B%BE%E7%89%87.md)。

---

材料为两则通讯记录，通讯方是深入禁域的五队，接听方是留守终端的记录员。二人以对白推进，笔录式的叙述夹在其间。

**编号 03833**。通讯联通后，记录员请五队汇报例行调查记录。人员情况为“应到六人，实到一人，两人返程”；记录员按惯例不在口头简报中报殉职人数，只自行在笔录里补记“三人失联”。设备方面，五队报告“无”正常运作的设备——一周前起全部实验设备处于“过敏状态”，即测量目标或运行环境的某个关键参数远超设备额定值而导致的异常；这在禁域调查中并不少见，法术相关设备在环境场流极高时还会无法关闭。

五队随后补报了一项变化：当前区域周围出现大量建筑物，规模巨大且绝大部分残破；大致环境仍是“广袤的，略有地势起伏的绿‘草’地”，但三天前地面已可见疑似建筑的混凝土与红砖，随着进度推进，建筑群的结构逐渐完整。影像与坐标将在记录结束后上传终端。记录员听到“建筑物”时下意识直起身子靠近终端，随即说出：

> “不要进入。”

五队回复“了解”。

**编号 03834**。例行状况汇报过后，上级下达新指令：研究资料后将建筑群外观群落定义为“实体”，并为调查任务增添条目，要求五队带回一份实体内部观察报告。记录员想起自己昨日脱口而出的“不要进入”——那与其说是指示，不如说是同事之间的关心，他因此在提交报表时被领导口头警告。昨日汇报结束后传来的图像满是噪点，给他一种不安的感受：那些灰色带窗的混凝土方块只在第一印象上给人建筑物的感觉，在茫茫无际的“草”地上如同从半空洒落般毫无章法地斜插着，残破、冷寂，他不敢久看那黢黑的窗口。

五队请求就近调查（当前坐标与上次汇报相距约 20 公里），获批准。追问补充情况时，五队答“图像将在记录之后传回终端”。记录员皱眉再问“补充信息只有图像吗”，终端另一头的队长似乎思考了一会：

> “是，只有图像”
