# 素材池 目录说明

[在 My Project 中编辑](https://chatgpt.com/space/page_3fa38183fb748191a104934dc3543242)

本目录收录**叙事性写作素材**（事件块原文、场景、对白断章等），与正式条目分离：

- 素材页 = 整理后的内容记录（分段梳理）+ 素材卡

- 被其他条目引用为正典事实时，引用方须注明出处页；

- 全部事件块素材按原始标题命名（如 `调查记录.md`）；事件块中“词条性质”的内容已转化为正式条目（如 `02-地理地区/柏格宁.md`、`03-组织势力/赫拉小队.md`、`06-能力与超常/魔与法.md`），不在此重复建档；

- metree page13（AI 稿支线）等 metree 来源素材页也存放于此，frontmatter `canon: 弃稿` 标注。

现有素材页见[总索引](../../00-%E5%AF%BC%E8%A7%88%E4%B8%8E%E7%B4%A2%E5%BC%95/%E6%80%BB%E7%B4%A2%E5%BC%95.md)（章节：09 作品与写作素材）。
