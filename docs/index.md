# 陆拾肆企划

法术走入城市， 未知仍在边界之外。

在一些地方，学校已经把有关法术的古籍编入教材；在另一些地方，人们仍只能从传闻中想象法术。神魔以信仰与恐惧为食，柏格宁港在战后兴建，而一次宣称成功的登月至今留下争议。
