# 查询定义

原站点查询条件保留如下，供核对分组和筛选口径。

```yaml
# 人物角色总览
#
# Obsidian Bases 查询（Quartz 5 bases-page 插件在构建时渲染为静态表）。
# 数据与呈现分离：本文件只声明"查什么、显示哪些列"，数据全部来自各条目
# 的 frontmatter。新增一个角色条目 -> 本表自动多一行，无需改导航页。
#
# 注意：本 wiki 用 frontmatter 的 type 字段（值=角色）标注条目类型，
# 而不是 tag，所以过滤用 note.type 表达式，不要用 file.hasTag("角色")。
views:
  - type: table
    name: 按完成度分组
    filters:
      and:
        - note.type == "角色"
    groupBy:
      property: note.status
    order:
      - file.name
      - note.status
      - note.canon

  - type: table
    name: 全部角色（按正典性）
    filters:
      and:
        - note.type == "角色"
    groupBy:
      property: note.canon
    order:
      - file.name
      - note.status

properties:
  file.name:
    displayName: 条目
  note.status:
    displayName: 完成度
  note.canon:
    displayName: 正典性
```
