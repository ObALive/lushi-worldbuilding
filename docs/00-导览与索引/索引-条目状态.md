# 查询定义

原站点查询条件保留如下，供核对分组和筛选口径。

```yaml
# 条目状态总览
#
# 全站条目按 type / status / canon 三个 frontmatter 枚举字段汇总。
# 在原 markdown 仓库里这三项只能靠人工清点；这里由查询直接生成。
#
# 【本页同时是一个数据卫生检查器】
# status 的合法取值只有 4 个：完整 / 较完整 / 草稿 / 骨架。
# 如果某行的"完成度"显示成一句带括号的长说明，说明该字段越界了——
# 那正是审计报告指出的问题（取值混入说明文字会让排序/分组失效）。
views:
  - type: table
    name: 按类型分组
    filters:
      and:
        - file.hasProperty("status")
    groupBy:
      property: note.type
    order:
      - file.name
      - note.status
      - note.canon

  - type: table
    name: 按正典性分组
    filters:
      and:
        - file.hasProperty("status")
    groupBy:
      property: note.canon
    order:
      - file.name
      - note.type
      - note.status

properties:
  file.name:
    displayName: 条目
  note.type:
    displayName: 类型
  note.status:
    displayName: 完成度
  note.canon:
    displayName: 正典性
```
