# 查询定义

原站点查询条件保留如下，供核对分组和筛选口径。

```yaml
# 历史事件索引
#
# 按正典性分组的事件条目。原有工作流需要在 meta/待决问题与冲突清单.md 里
# 人工比对"哪些条目口径未定"，这里改为直接查询 canon 字段。
views:
  - type: table
    name: 事件一览
    filters:
      and:
        - note.type == "历史事件"
    groupBy:
      property: note.canon
    order:
      - file.name
      - note.status
      - note.canon

  - type: table
    name: 按完成度
    filters:
      and:
        - note.type == "历史事件"
    groupBy:
      property: note.status
    order:
      - file.name
      - note.canon

properties:
  file.name:
    displayName: 事件
  note.status:
    displayName: 完成度
  note.canon:
    displayName: 正典性
```
