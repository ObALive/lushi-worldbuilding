# 卡兹米娅家变

[在 My Project 中编辑](https://chatgpt.com/space/page_0a89082288b88191bc1fb7fdd77d5134)

**概述**：1979 年下界卡兹米娅家族因家长继承之争内乱，次子借斯托多衮家族之力上位，反遭其里应外合、屠城灭族；该次子正是[拜尔丹·卡兹米娅](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E6%8B%9C%E5%B0%94%E4%B8%B9%C2%B7%E5%8D%A1%E5%85%B9%E7%B1%B3%E5%A8%85.md)的父亲，家族七零八落后她流亡主界。

## 经过

- 背景：卡兹米娅家族的权势与威望在很长一段时间内与斯托多衮家族相当。

- 导火索：家族内部因下一任家长之争内乱严重。

- 经过：次子暗中借助斯托多衮的力量成功上位；斯托多衮趁虚而入、全力出战、里应外合——在求援讯号来不及发出的情况下控制家族核心成员，以诱骗等方式逐个战胜卡兹米娅家族各诸侯；为斩草除根，进行了相当长时间的大规模屠城。

- 这位借用他族力量的次子正是卡兹米娅的父亲。

- 结局：卡兹米娅氏族分裂四散，拜尔丹·卡兹米娅流亡主界。
