# 法术革命

[在 My Project 中编辑](https://chatgpt.com/space/page_6dea6506f90881919d07557aedf10998)

法术革命是近代对[法术](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E6%B3%95%E6%9C%AF%E4%BD%93%E7%B3%BB.md)的系统研究逐步兴起，并影响教学与社会生活的历史过程。古籍已有法术现象的记载。直到近代，各地居民接触法术的机会仍相差很大。

## 从古籍考证到公开争论

法术协会曾陆续证实古籍中的若干记载，并研究其中的机理。1888 年，与协会对立的几个国家宣布登月成功，借此回应古籍中“不可触之月”的说法。次年，协会管辖地区的学校修订教材，将“不可”究竟指“不可能”还是“不可以”列为未决问题。这场争论从研究者之间扩展到了学校和公众。详见[不可触之月](%E4%B8%8D%E5%8F%AF%E8%A7%A6%E4%B9%8B%E6%9C%88.md)。

## 施法者研究

到 1901 年，国际法术协会已对五十万名长期法术使用者进行抽样调查，并公开发表了有关施法与精神健康的报告。[《法术学导论》](../06-%E8%83%BD%E5%8A%9B%E4%B8%8E%E8%B6%85%E5%B8%B8/%E6%B3%95%E6%9C%AF%E5%AD%A6%E5%AF%BC%E8%AE%BA.md)记述了调查结果，以及职业选择对解释这些结果的影响。

## 地域差异

自然场流充足的地区可以长期利用当地的特殊材料，逐渐形成各自的施法传统。大片场流微弱的平凡之地则缺少这些材料，居民日常也难得见到施法。1889 年，法术协会管辖地区的学生已在教材中读到古籍争议。到了[第三次世界大战](%E7%AC%AC%E4%B8%89%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98.md)期间，仍有人把法术当作传说，希望能到法术兴起的大陆亲眼见证。
