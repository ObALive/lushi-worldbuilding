# 法术革命

[在 My Project 中编辑](https://chatgpt.com/space/page_6dea6506f90881919d07557aedf10998)

法术革命即第三次世界大战。战争在各地陆续结束，古德尔地区于 1897 年停战，世界范围的战争于 1900 年走向结束。战后，[法术](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E6%B3%95%E6%9C%AF%E4%BD%93%E7%B3%BB.md)正式进入大众视野并得到社会接纳，成为战后社会的重要组成部分。

## 基本信息

| 项目 | 内容 |
|---|---|
| 时间 | 各地陆续结束；1897 年古德尔地区停战，1900 年世界范围走向结束 |
| 范围 | 全球 |
| 相关机构 | 法术协会，诞生于革命之初 |
| 结果 | 法术得到社会接纳 |

## 影响

革命结束后，法术与科技并存于社会生活中。1901 年国际法术协会发布长期施法者精神健康调查报告，1903 年联合国授权[异常协会](../03-%E7%BB%84%E7%BB%87%E5%8A%BF%E5%8A%9B/%E5%BC%82%E5%B8%B8%E5%8D%8F%E4%BC%9A.md)调查世界各地的禁域。

战后建设与贸易也改变了城市发展。[柏格宁](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E6%9F%8F%E6%A0%BC%E5%AE%81.md)在当地停战后得到拨款建设港口，并于 1900 年投入使用；[白萨尼斯](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E7%99%BD%E8%90%A8%E5%B0%BC%E6%96%AF.md)的首都则在法术革命后被称为“商业界的耶路撒冷”。
