# 第三次世界大战

[在 My Project 中编辑](https://chatgpt.com/space/page_170b17f1fd9881918dcc3def3c906674)

第三次世界大战，简称三战，是一场以国家间地缘政治利益冲突为主因的世界大战。各地陆续停战，古德尔地区在世界范围的战事走向结束前三年就已开始重建。

## 战时生活

[澜星](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E7%80%9A%E6%B5%B7%E9%98%91%E5%B9%B2%E7%99%BE%E4%B8%88%E6%98%9F.md)失忆前与男友在白撒尼斯躲避战火。两人把前往法术兴起的大陆，当作战后最想实现的旅行愿望。

## 各地停战与重建

1897 年，古德尔地区的战事结束。当地政府随即拨款建设[柏格宁](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E6%9F%8F%E6%A0%BC%E5%AE%81.md)港。1900 年，世界范围内的战争走向结束，柏格宁港也于这一年建成并投入使用。建港吸引了外来投资，铁路、仓储与航运业随之发展。政府曾以桥上房产向当地居民支付战后补偿。

战后，[白萨尼斯](../02-%E5%9C%B0%E7%90%86%E5%9C%B0%E5%8C%BA/%E7%99%BD%E8%90%A8%E5%B0%BC%E6%96%AF.md)的首都白萨尼斯城以商业都会闻名，得名“商业界的耶路撒冷”。
