# 毕格兰特洲

[在 My Project 中编辑](https://chatgpt.com/space/page_9cc4e40b1908819181872e9df969df71)

毕格兰特洲各国为满足不断增长的生产需求，先后经历了数次工业革命。随着工厂扩大生产、企业之间的分工日益细密，居民取得生活物资的方式也逐渐改变。越来越多的人在生产过程中只负责一道工序，用这份工作的报酬购买其他人提供的商品和服务。

## 各国经济现状

截至1900年，生活物资订阅在毕格兰特洲仍在扩张。对全洲半数以上的中低收入居民而言，按自家的收入、日常用量和能够承受的开支计算，订阅已是维持日常生活最合算的选择。按次购买、从零散摊贩处购买食材和在家加工仍然可行。用量少或收入不定的家庭，即使单买的价格较高，也可能更愿意保留随时少买或停买的余地。

### 生产分工与原料供应

食品供应就是一例。随着加工厂和大型零售商成为主要买家，农产品从产地成批运往工厂，再以净菜、果蔬罐头等形式进入超市。生产者按统一规格整批交货，可以省去分拣小份、逐户出售的工夫。能直接向农户进货的摊贩随之减少，部分居民即使仍愿意自己做饭，也很难在住处附近按所需分量买齐未经加工的食材。

类似的分工也出现在工业生产中。原料和半成品多按企业的用量和规格交易，机器、加工场地和销售渠道掌握在能够为之出资的业主手中。熟练工人离开岗位后，仍有手艺，却未必能买到少量材料、用上配套设备，或独立做出一件可以出售的成品。生产规模越大，决定生产什么、以何种形式出售的权力也就越集中在设备和渠道的所有者手中。

### 生活物资的订阅

许多供应商为订购一个月或更久的顾客提供折扣。以萝卜为例，若零买一根要花3元，付30元订一个月则每周可收到一箱。经常做饭、吃得完这份菜的家庭采用月订，可以省下一笔实在的开支。对供应商而言，这笔折扣换来一个月的订单，采购、加工和配送都可按已知订量安排。顾客也提前承诺了这段时间的支出，即使中途遇到更合意的摊贩，原套餐的费用仍须承担。

订阅折扣按账户提供。若几户合订一份大套餐，便可以共同享受按量折算的低价，供应商却只能取得一份订费。部分公司因此把共用账户列为违反用户协议的行为。一箱菜送到后，家庭怎样分食很难查验。公司能做的是累积账户使用中的零散迹象，据此判断是否有多户长期共用，并可能停用账户。依靠同一账户领取物资的家庭也会一同失去原有的订购条件。

### 工资结算与失业

越来越多企业按全年安排报酬，仍逐月发放基本工资，同时压低月薪在全年报酬中的比重，把更多收入放到年终奖中。对雇主来说，年终给付有留住职工的作用。年中换工作的人除了比较两家的月薪，还得算上离职可能放弃的年终报酬。接近结算时，这笔损失可能让职工即使找到工资更高的岗位，也难以立即离开。

家庭的账单却有各自的到期日。全年收入足以支付全年生活费的职工，平月手头也可能少有余钱。一旦失去正式岗位，月薪中断，原本指望到年末领取的收入也可能落空，已经订下的物资和服务仍要按约付款。多项欠款和违约负担叠加时，个人可能因此破产。

### 众包用工

众包用工源于资方对劳动力的两重需要。维持一定的失业率，意味着招聘时总有一批人在等正式岗位。现有职工要求加薪或拒绝不利条件时，雇主容易找到替代人选。对企业来说，这批等待招工的人也能带来收益。他们有现成的手艺，又往往等不起下一轮招聘。把新增的配送、维修等工作拆成零单交给个人，企业就能继续从这些人的劳动中获利，同时控制正式岗位的数量。

用工企业按完成的任务付费，订单减少时便能缩减人工开支。两单之间可能隔几个小时，也可能隔上几天，这段时间没有报酬。临近缴费日的承接者尤其难以拒绝低价。承接者按个人外包条件工作，缺少正式雇员享有的劳动合同保障。顾客可以低价购买这些服务，但如果维修出了问题，公司也不为个人承接的工作提供质量担保。

这些零工承接者本身也是廉价服务的顾客。一个人可以靠送货所得支付修理费，而接下修理任务的人也可能靠同样的零工收入购买生活服务。众包因而同时成为部分家庭取得收入和压低开支的途径。

### 劳动市场与家庭消费

企业分别决定留多少正式职工、把多少活交给个人。许多企业都选择按件发包时，即使配送和维修的工作量增加，稳定岗位也未必随之增加。靠零工过日子的人仍在等正式职位，继续与在岗者竞争。

对掌握工厂、货源和销售渠道的业主来说，订户提前承诺购买，工人可以按需要增减，经营中有两笔账相对容易安排。对缺少积蓄的家庭来说，同一套安排意味着收入可以随订单减少，已经订下的生活开支却很难同样迅速地缩减。手头宽裕的家庭则更能承受单买的较高价格，也有余地等一份待遇合适的工作。

企业在用工和销售上也面对不同的利害。作为雇主，压低报酬、少作长期用工承诺可以节省开支。作为供应商，要让订阅比逐次销售更可靠，又需要足够多的家庭有稳定收入、能够按期付款。当低薪和不稳定用工扩及更多行业时，一家企业节省的工资，可能正是另一家企业的顾客原本用来续订的钱。
