# 毕格兰特洲

[在 My Project 中编辑](https://chatgpt.com/space/page_9cc4e40b1908819181872e9df969df71)

毕格兰特洲各国经历了数次工业革命。生产分工也改变了居民取得生活物资的方式。农产品从产地送往加工厂，再由超市以罐头、净菜等形式出售。工业原料和半成品主要在企业之间流通，居民即使会加工，也越来越难以按家庭所需的分量买到原料或取得合用的设备。

## 各国经济现状

截至1900年，生活物资订阅在毕格兰特洲仍在扩张。对全洲半数以上的中低收入居民而言，按自家的收入、日常用量和能够承受的开支计算，订阅已是维持日常生活最合算的选择。按次购买、从零散摊贩处购买食材和在家加工仍然可行。用量少或收入不定的家庭，即使单买的价格较高，也可能更愿意保留随时少买或停买的余地。

### 生活物资的订阅

供应商把原先逐次出售的商品改为按月或更长时间订购。例如，萝卜仍可按根零买，订购一个月则每周配送一箱。经常做饭的一家人用得完这份菜，折算下来每根便宜得多。供应商由此提前锁定一个月的销路，家庭也提前承诺了一个月的支出，在订期内换一家买菜仍须承担原套餐的费用。

部分供应商通过用户协议限制多人共用订阅账户。家庭怎样分食送到手的蔬果很难查验，但多项零散的使用记录若持续显示账户由多人共用，供应商可能据此停用账户。依靠同一账户领取物资的几户人家会一同失去原有的订购条件。

### 工资结算与失业

企业逐渐把更多报酬放到年末结算。职工平时仍领月薪，但月薪占全年报酬的比重下降，年终奖所占的比重上升。对已经订下多项生活服务的家庭，全年收入即使足以覆盖全年开销，平月能动用的钱也可能很少。年中离职可能损失尚未取得的年终报酬，原有订约的付款期限仍照常到来。失业持续越久，家庭越难履约，严重时累积的违约负担足以使个人破产。

### 众包用工

部分企业把配送、维修等工作拆成单项任务，交由个人承包，按件支付较低报酬。失去固定岗位的人可以靠接单应付眼前的账单，却无法保证下一笔收入何时到来。承接者按个人外包条件工作，缺少正式雇员享有的劳动合同保障。顾客购买这类价格较低的服务时，公司也不为个人承接的工作提供质量担保。

这些零工承接者本身也是廉价服务的顾客。一个人可以靠送货所得支付修理费，而接下修理任务的人也可能靠同样的零工收入购买生活服务。众包因而同时成为部分家庭取得收入和压低开支的途径。
