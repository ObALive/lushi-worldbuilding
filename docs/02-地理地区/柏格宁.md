# 柏格宁

[在 My Project 中编辑](https://chatgpt.com/space/page_9303fb4f90808191ab664d49c8ba5518)

柏格宁又称拜格宁，是一座位于大江入海口的港口城市，降水丰沛、水网密布。城市随战后建港与航运发展迅速扩张，市中心建在跨江大桥上，繁华外观与基础设施欠缺的荒楼区并存。

## 地理与风貌

柏格宁降水丰沛，水网密布，郊区有一片被划为生态公园的湿地。入海大江宽数公里，市中心大桥也宽数公里，城市核心设施与主要建筑集中在桥上。城内另有老城区。

## 历史沿革

柏格宁曾是一处位于国土边境的海边小渔村，后来逐渐发展为港口城市。

- 数年前：仅为一块毫无治安可言的"小村子"。

- 港口价值获认可后：开始被作为受政府行政管理的地带看待。

- 1897 年，古德尔地区在[第三次世界大战](../05-%E5%8E%86%E5%8F%B2%E4%BA%8B%E4%BB%B6/%E7%AC%AC%E4%B8%89%E6%AC%A1%E4%B8%96%E7%95%8C%E5%A4%A7%E6%88%98.md)中的战事结束。政府随后拨款建设柏格宁港。

- 1900 年：完成对拜格宁港的建设并全面投入使用。

- 至 1905 年：港口相关产业链正处于激烈竞争中（"随着竞争一同发展的铁路网络，工业园区，物流网络，金融产业和仓储业"），以极大的竞争优势逐渐成为整个古德尔乃至周边国家的依赖。

- 1905 年后：行业竞争尘埃落定，存活的几家企业瓜分产业市场、完全形成垄断；在之后的十余年内逐渐提高服务报价，进入垄断企业的敛财阶段。

## 当地势力

地方势力以长期扎根当地的码头帮派和家族为基础，外来资本通过与它们合作参与港口开发。政府为维持稳定与其订立协议，让出大量港口收益；这些势力逐渐发展为垄断企业，同时保留了相当数量的非法武装。

各家掌握自己的码头与街区，经营业务有所重叠，也各有侧重。它们共同参与大型港口设施，平时合作维持秩序，同时争夺客户与利益。企业的首席执行官等公开经营者主要承担门面职能，实际决策由幕后掌权者控制。

家族对辖区居民的传统照应随着企业化和资本进入逐渐衰退。亲信与长期依附的老工人仍能得到照顾，外来人口和临时工更多作为廉价劳动力受雇，各家保留传统的程度有所差异。

## 地方治理

[柏格宁城建负责人](../04-%E4%BA%BA%E7%89%A9%E8%A7%92%E8%89%B2/%E6%9F%8F%E6%A0%BC%E5%AE%81%E5%9F%8E%E5%BB%BA%E8%B4%9F%E8%B4%A3%E4%BA%BA.md)负责桥城工程及相关建设事务。地方治安负责人直接管理巡查队，其下属的本土警力领导负责日常警务。巡查队承担异常巡查与清理协调，受雇的[行脚商](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E8%A1%8C%E8%84%9A%E5%95%86.md)提供额外的处置能力。

建设一方掌握工程资料，治安一方承担持续异常带来的处置压力。双方围绕清理费用、现场配合和事故责任发生分歧，又依靠合作维持设施使用与城市秩序。地方势力分别就建设项目、地盘秩序和异常造成的影响与相关负责人交涉。

[世界警署](../03-%E7%BB%84%E7%BB%87%E5%8A%BF%E5%8A%9B/%E4%B8%96%E7%95%8C%E8%AD%A6%E7%BD%B2.md)由路易斯带队介入当地治安。巡查队在现场安全、伤亡事件和异常线索等事务中与世界警署发生协作。

## 桥城与荒楼区

港口价值受到重视后，大量基建拨款与外商投资涌入柏格宁，推动了桥城建设和房地产泡沫。桥上城区的规模远超当时城市能够支撑的体量。大桥兴建之初，楼盘便已售出或用于支付建桥薪水；政府还曾以“桥上别墅”支付战后补偿，按当时市价估算，别墅价值为补贴款的三倍。

分给原住民与底层居民的部分房产后来成为荒楼区。高昂的基础设施费用、停水停电与社区停摆，使这些房产失去实际生活保障。荒楼保留着粉饰华美的外墙，内部则是肮脏的毛坯。繁华建筑与道路设计遮蔽了楼宇间的入口，距离误差和空间错位进一步掩藏这些区域，地图与导航中的相关信息也被撤去。

更多获得补偿房产的人选择弃房谋生，在城市中从事低薪的底层工作。他们的家产毁于战争，政府又已将房产计作补偿，生活因而依靠重新出卖劳力维持，补偿与维权的诉求陷入困境。继续留在荒楼区的人多受过沉重打击，或因自身处境而缺少工作能力，逐渐形成流浪汉聚落。毛坯楼为他们提供了遮风避雨和落脚的空间。

荒楼区居民仍与城市保持往来，外出工作或寻找维持生计的机会。市容驱赶主要针对衣着、露宿状态等外观被认定为影响市容的人，日常出入因此受到选择性的排斥。

## 桥城异常与清理

桥城工程依赖一种含有水中战士遗骸的特殊建筑材料，这种材料是工程得以实施的关键条件。大桥投入使用后，材料持续引发异常，荒楼区和桥下空间尤为严重。零星异常构成日常风险，施工和建筑损坏等刺激会使情况加重。清理能够暂时缓解危险，材料则继续留在建筑中，政府主要通过持续处置维持局面。

多数亡灵由死者残留的记忆、情绪与行为习惯构成，会重复战斗、巡逻，或对特定声音、动作和物件作出反应。这些反应具有一定稳定性，长期接触者能够积累应对经验。亡灵将眼前事物与残留记忆联系起来时，会出现认识上的错位，使日常活动也可能引发危险。少数个体保留着较完整的意识、自我认识与交流能力，其见闻取决于生前经历和留存的记忆。

生活在桥城、废弃建筑和桥下的动物受到异常环境影响，逐渐出现躁动、凶猛与行为失常。它们仍保留觅食、护巢等习性，异常使相关行为变得激烈或紊乱。居民也会出现疲惫及其他状态变化，部分区域发生袭击事件。

局部异常加重时，亡灵活动、动物躁动和居民不适可能相继出现。施工、破损及激烈冲突能够同时刺激附近的多种异常；动物造成的声响与破坏可能触发亡灵残留的行为，亡灵活动又会惊扰动物，使现场进一步混乱。

政府秘密雇佣行脚商，并通过以城管身份活动的巡查队组织异常处置。巡查队接收报告、协调现场和受雇人员，并记录清理结果与复发情况。基层清理者通常只接到地点发生异常和需要清理的目标等任务信息，前往现场时乘坐门窗封闭的车辆，所在区域及其与大桥的关系一并受到保密。

早期清理工作中，战争伤亡造成的遗留问题是普遍采用的解释。世界其他地区也有类似案例，柏格宁桥上的规模与发生频度则更高。城建负责人和建桥核心参与者依据工程经历，对特殊材料与异常的关系产生联想和猜测；长期参与清理的人员则逐渐接触到可能关联建筑材料的零散线索。遗骸成分与建设内幕由少数相关者掌握，政府对清理者提供的信息主要围绕任务目标与处置要求。
