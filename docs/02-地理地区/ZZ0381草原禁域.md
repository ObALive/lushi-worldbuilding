# ZZ0381草原禁域

[在 My Project 中编辑](https://chatgpt.com/space/page_e1a66901e3a0819189abc38cf6b1829b)

**概述**：“草原”是位于**世界几何中心**的一处禁域，千百年来没有任何人进入过“草原”深处的记录。但实际上，**“草原”只能进去，无法出来**——所有进入者都会在世界的信息层面被逐渐遗忘。

## 档案（异常协会资料局 · 编号 ZZ0381）

- 名称：ZZ0381—"草原"（已归档禁域）。

- 责任探查小组：五组#1898。

- 档案记载的地图测绘面积为 2530 平方公里。因内部空间放缩，实际面积估计超过 8000 平方公里。当地[法术场流](../01-%E5%9F%BA%E7%A1%80%E8%AE%BE%E5%AE%9A/%E6%B3%95%E6%9C%AF%E4%BD%93%E7%B3%BB.md)极为剧烈，除草地外未见其他生命迹象。

- 周边调研：相关异常现象记录历史 1000 余年（仅可追溯年限）；"没有任何深入'草原'的案例，不是没有生还案例，是完全没有深入'草原'的案例"；当地聚落（历史上以畜牧业为生）的活动范围仅限于禁域边缘两公里以内。

- 提档记录：档案"大概在五年之前"建档，系自"前机构"接手；长期按一级险域建档（依据仅为人员失踪案例）。核查后决定："将 ZZ0381 提档为禁域，并组织一次外围险域探查。"

## 规则/机制

- **只能进，不能出**：“草原”的空间可以以四维空间来理解——当任何物体往草原中心方向走时，会因这片区域特殊的空间构造，顺着“地势”往第四维的另一个方向滑去；而朝外走时，现实物体与生物都是三维构造，没有在第四维上主动运动的能力，无法逆着“地势”回到“草原”之外。

- **越深越隔绝**：对世界上一切事物来说，每往草原深处走一步，就相当于踏进一层更深的、与外界隔绝的世界。完全走入草原的人，无论如何往外走都走不到头；但只要往里走一步就会陷得更深。

- **被遗忘**：所有进入“草原”的事物都会被外界遗忘——在信息层面彻底离开原本的世界。这解释了档案中探索次数异常等现象（进入者被遗忘后，记录与记忆也随之缺损）。
