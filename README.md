# 陆拾肆企划世界观资料

本仓库保存 My Project 资料空间中该分支的版本快照，用于查看差异、追溯历史和恢复资料。首次快照日期为 2026 年 11 月 16 日，共 88 个页面。

[空间中的编辑入口](https://chatgpt.com/space/page_506ceb47a36081919831b478640e9b94) · [仓库阅读入口](docs/index.md)

## 维护方式

日常编辑继续在 My Project 进行。本机 Codex 定时任务“My Project 同步至 GitHub”每小时检查三个资料分支，将变化同步到各自仓库的 `main` 分支；没有变化不创建提交。任务需要本机 Codex 能够运行，当前采用定时检查，并非编辑事件触发的云端同步。GitHub 修改不会自动回写空间。

每次提交以实际差异说明新增、修改或删除的内容，使用中文标题和明细。同步保留正文、附件、配置表与内容关系；读取不完整时保留现有文件，冲突时不覆盖未提交工作、不强推，推送后核对远端提交。

正文位于 `docs/`，库内链接已转换为相对路径，跨分支链接指向对应 GitHub 仓库。`.pages/snapshot.json` 保留原页面块、维护指令、顺序及元数据，`.pages/manifest.json` 保存空间与文件映射；附件位于 `assets/`。附件中的旧归档保留原有版本，现行正文以本次从空间读取的页面为准。

世界观的分类、属性、别名、标签、查询表和页面关系一并保存。
